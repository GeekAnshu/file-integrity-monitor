# 🛡️ File Integrity Monitor

A browser-based cybersecurity tool that uses SHA-256 cryptographic
hashing to detect changes to files.

## Features

- SHA-256 hash generation
- File selection through browser
- File size detection
- Integrity baseline creation
- Hash comparison
- File modification detection
- Copy hash functionality
- Responsive cybersecurity-themed interface
- No backend required
- No external API required

## Technologies

- HTML5
- CSS3
- JavaScript
- Web Crypto API

## How It Works

The application generates a SHA-256 cryptographic hash from the
selected file.

A hash acts like a digital fingerprint for the file.
